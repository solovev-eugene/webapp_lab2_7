# Веб-сервис на Flask (Лабораторная работа №2.7)

## Описание

Это веб-сервис, разработанный на Python с использованием микрофреймворка Flask. Проект создан в рамках выполнения лабораторной работы и демонстрирует базовую структуру веб-сервисв с API. В качестве модели данных используется PostgreSQL. Приложение принимает запросы к базе данных и выводит ответ в виде JSON. 

Приложение служит основой для дальнейшего развития и изучения возможностей Flask, включая обработку моделей данных, валидацию данных и взаимодействие с окружением.

## Установка

Для установки приложения необходим установленный docker

1. Клонируйте репозиторий
```bash
git clone https://github.com/solovev-eugene/webapp_lab2_7.git
cd webapp_lab2_7
```
2. Установите виртуальное окружение и зависимости
```bash
python -m venv .venv

source venv/bin/activate # Для Linux/macOS
venv\Scripts\activate # Для Windows

pip install python-dotenv flask flask-sqlalchemy flasgger psycopg2-binary
```
3. Запустите docker-контейнер
```bash
docker run -d \
	--name diseases_psql \
	-e POSTGRES_USER=someuser \
	-e POSTGRES_PASSWORD=password \
	-e POSTGRES_DB=diseases_db \
	-p 5433:5432 \
	-v pgdata:/var/lib/postgresql/data \
	postgres:16-alpine
```
4. Создайте базу данных
```bash
python create_db.py
```
5. Настройте переменные окружения
```bash
cp .env.example .env
```

## Использование
После выполнения всех шагов по установке, запустите сервис:
```bash
python app.py
```

Откройте ваш веб-браузер и перейдите по адресу http://127.0.0.1:5000. Вы увидите главную страницу сервиса. Далее вы можете взаимодействовать с ним как через интерфейс Swagger, так через HTTP-запросы.
